# 🛍️ Adidas Clone Website (React JS)

A modern, responsive Adidas-inspired e-commerce website built using **React JS**. This project replicates the core UI and basic functionality of an online shopping platform, focusing on clean design, reusable components, and smooth user experience.

---

## 🚀 Features

* 🏠 Home page with banners and featured products
* 👟 Product listing page
* 🔍 Product detail page
* 🛒 Add to cart functionality
* ❤️ Wishlist feature (optional)
* 🔄 Dynamic routing using React Router
* 📱 Fully responsive design
* ⚡ Fast performance with React hooks

---

## 🛠️ Tech Stack

* **Frontend:** React JS
* **Styling:** CSS / SCSS / Tailwind (depending on your setup)
* **Routing:** React Router DOM
* **State Management:** Context API / Redux (optional)
* **Icons:** React Icons

## ⚙️ Installation & Setup

1. **Clone the repository**

```
git clone https://github.com/anshp2931-gif/adidas-clone.git
```

2. **Navigate to project directory**

```
cd adidas-clone
```

3. **Install dependencies**

```
npm install
```

4. **Start the development server**

```
npm start
```

The app will run on:

```
http://localhost:3000
```
